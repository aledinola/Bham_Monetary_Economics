# Assignment Workshop: A Two-Period Economy with Income Risk

[main_davila.m](main_davila.m) solves the two-period production economy with uninsured labour-income risk, using the assignment's baseline parameters. Households choose saving at given prices; damped capital iteration finds the competitive equilibrium.

Set this folder as MATLAB's current folder and run `main_davila`. The script prints equilibrium capital, factor prices and consumption, then draws capital supply and demand and compares two income-risk levels. Edit the parameters at the top to explore other examples.

All helper functions are included in the script. Only base MATLAB is required. Running it clears the workspace and closes existing figures. Set `export_figures = true` to save the two diagrams beside the script.

The accompanying slides are in Dropbox at `2026_2027/1_lectures/Assignment_workshop.pdf`. See the [course MATLAB inventory](../../MATLAB_INVENTORY.md) for related material.
